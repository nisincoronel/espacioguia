# Espacio Guía — Web v2

Versión revisada para acercarse al mockup visual de referencia.

## Estructura
- `index.html`: contenido y secciones.
- `styles.css`: estilos responsive.
- `script.js`: menú móvil, enlaces provisionales, navegación activa.

## Vista local
Abrí `index.html` en tu navegador. Para mejores resultados, usá Live Server.

## Publicación en Cloudflare Pages
1. Subí los archivos a un repositorio GitHub.
2. Cloudflare → Workers & Pages → Create → Pages → Connect to Git.
3. Framework: None.
4. Build command: vacío.
5. Output directory: `/` o `.` (según interfaz).
6. Deploy.

## Antes de publicar como sitio definitivo
- Confirmar dirección de contacto.
- Revisar la fotografía del hero y fotos de cursos.
- Confirmar estado real del curso destacado y enlaces.
- Conectar redes y páginas institucionales.
- Definir el logo vectorial definitivo.
